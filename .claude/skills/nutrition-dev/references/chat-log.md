# Разбор журнала чата

Журнал (`chat_log.py`) хранит не только текст, но и что агент ПОНЯЛ:
`trace.intent`, профиль с ограничениями, поисковый запрос, фрагменты,
блюда плана по дням, ответы модели по узлам. Почти все баги проекта
тихие — по паре «вопрос → ответ» их не видно, по trace видно.

В записях вес, возраст и диагнозы. Не копируй их в отчёт сверх нужного
для разбора и никуда не отправляй.

## Порядок

1. **Сводка по журналу** — скриптом, из корня проекта (модель не нужна):

   ```bash
   PYTHONIOENCODING=utf-8 python .claude/skills/nutrition-dev/scripts/triage.py logs/chat-2026-10-20.jsonl
   ```

   Для каждой записи — замечания: ошибка и трассировка, медленно,
   остатки PMID в показанном тексте, вопрос ушёл в ветку плана, блюдо
   плана не прошло бы НЫНЕШНИЙ фильтр ограничений (с ингредиентом
   из состава), повтор плана дал другое меню.

   Подробно одну запись: `--turn N` (trace целиком).

2. **Отделить «уже починено» от «живёт сейчас».** Нарушение, которое
   нынешний фильтр уже ловит, и повтор, давший другое меню, — признак,
   что дефект исправлен после записи. Подтверди: найди коммит
   (`git log -S`, `git log --since`). Живой дефект — тот, что
   воспроизводится на текущем коде.

3. **Воспроизвести.** План — `chat_log.replay_plan(agent, trace)`:
   узел make_plan модель не вызывает, повтор бесплатный и точный.
   Маршрут и ответы модели — по `trace.nodes[*].llm[*].response`:
   там сырой JSON до того, как код его отфильтровал.
   Стохастику маршрутизатора проверяй несколькими прогонами (≥2 на
   вопрос) с той же историей — один прогон ничего не доказывает.

4. **Каждый живой дефект** — по своей процедуре: утечка ограничения —
   `references/restrictions.md`, план — навык `measure-solver`, ответ
   по статьям — `references/rag-eval.md`. Тест — на наблюдавшийся случай,
   docstring говорит, что сломалось.

5. **Цены в плане смотри тоже.** Разбор журнала по всем прогонам нашёл
   подозрительно дешёвые блюда, которых не было в вопросе: чипсы по цене
   риса и картофеля (38–43 ₽/кг), раки по цене мороженой рыбы. Солвер под
   бюджет идёт именно за ними — правило «сканировать дешёвый конец» из
   CLAUDE.md.

## Отчёт

Таблица: запись → что видно → живой/починен (каким коммитом) → что делать.
Без персональных данных сверх необходимого.
