# Процедуры проекта

Почти все дефекты здесь тихие: код работает, тесты проходят, результат
неверен. Поэтому каждая процедура — это замер, а не чтение кода.
Выбери строку таблицы и прочитай ТОЛЬКО указанный файл.

| задача | читать | скрипт |
|---|---|---|
| запрещённое блюдо в плане, аллерген, новая категория, правка `_filter_catalog` | `references/restrictions.md` | `scripts/leak_scan.py` |
| «стало ли лучше» про ответы на вопросы, правка промптов, поиска, нарезки, прогон метрик | `references/rag-eval.md` | `experiments/run_noise.py`, `run_eval.py` |
| баг в разговоре, жалоба, разбор `logs/*.jsonl` | `references/chat-log.md` | `scripts/triage.py` |
| правка `solver.py`, весов, состава каталога | навык `measure-solver` | `experiments/measure_solver.py` |

Задача касается нескольких строк — читай файлы по очереди, в порядке,
в котором дефект проходит через систему (журнал → ограничение → солвер).
