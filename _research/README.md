# Материалы замеров

Здесь лежит доказательная часть проекта: почему каждая константа равна
тому, чему равна, и что именно было отвергнуто по дороге.

| Что | Содержимое | В репозитории |
|---|---|---|
| `EVOLUTION.md` | журнал решений: что пробовали, что померили, что отвергли | **да** |
| `dataset/` | вопросы, разметка релевантности, сохранённые ответы, выгрузки метрик | нет |
| `baselines/` | точки отсчёта для замеров солвера | нет |

Журнал едет в репозиторий намеренно: на него ссылаются `README.md`
и `CLAUDE.md`, и без него обе ссылки ведут в пустоту. Остальное —
десятки мегабайт рабочих данных, которые пересобираются скриптами
и продукту не нужны.

## Как это пересобрать

```bash
python make_eval_dataset.py              # вопросы из корпуса
python make_eval_dataset.py --references # эталонные ответы к ним
python build_qrels.py                    # разметка релевантности пулом
python run_eval.py                       # прогон агента и метрики
```

Дальше — замеры из пакета `experiments/`, каждый отвечает на один вопрос;
список в `experiments/__init__.py`, результаты пишутся в `dataset/`.

Всё это обращается к API и стоит денег: полный цикл — несколько долларов.
Для итераций хватает 80 вопросов вместо 210 (флаг `--n 80`).
