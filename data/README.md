# Данные

Два источника, оба открытые и без ключей.

| Источник | Что даёт | Объём |
|---|---|---|
| USDA FNDDS | готовые блюда с КБЖУ и весами порций | около 3000 блюд после отсева |
| PubMed | абстракты обзоров и мета-анализов по нутрициологии | 1604 статьи |

## Что где лежит

```
data/
├── raw/              28 МБ — сырьё, в репозиторий не идёт
│   ├── usda/survey/  выгрузка FNDDS: food, food_nutrient, food_portion, ...
│   └── pubmed_abstracts.json
└── processed/        756 КБ — готовые артефакты, едут в репозиторий
    ├── foods.parquet       каталог блюд с русскими названиями и отсевами
    └── corpus_index.json   doc_id → выходные данные статьи
```

Артефакты из `processed/` лежат в репозитории намеренно: больше половины
тестов стерегут **данные**, а не код, и без каталога они молча пропускаются.
Подробнее — в `tests/README.md`.

Векторный индекс живёт отдельно, в `lance_db/`, и в репозиторий не идёт:
44 МБ, тестам не нужен, пересобирается из `processed/`.

## Как пересобрать

Порядок важен: каждый шаг читает результат предыдущего.

```bash
python data_sources.py         # скачать сырьё (~30 МБ, бесплатно)
python foods.py --rebuild      # собрать каталог + проверка по Этуотеру
python translate_catalog.py    # русские названия
python review_catalog.py       # ревизия: доступны ли продукты в РФ и СНГ
python review_familiar.py      # ревизия: едят ли это блюдо у нас
python build_index.py          # векторный индекс
```

Три средних шага обращаются к модели и стоят денег: перевод 4800 названий
и две ревизии. Результаты кэшируются, повторный запуск бесплатен.

## Ловушки

**`nutrient_id` в сырых данных USDA хранит `nutrient_nbr`** — 208, а не 1008.
Перепутать значит получить нули вместо калорий, причём тихо. Для этого
в `data_preporation.py` стоит проверка по Этуотеру: сумма белков, жиров
и углеводов, умноженная на 4/9/4, обязана сойтись с заявленной
калорийностью.

**Исправления перевода живут только в `translation_fixes.py`.** Разовая
правка прямо в parquet держится до первой пересборки каталога, после чего
молча откатывается. Всё, что пишет `name_ru`, обязано вызвать
`translation_fixes.apply` последним шагом.

**Каталог — вход солвера.** Любое изменение его состава меняет то,
из чего собирается день, поэтому принимается так же, как правка самого
солвера: `python -m experiments.measure_solver`.

## Что отсекается из каталога

Отсекается **не иностранное**, а несъедобное и недоступное: дичь,
субпродукты, служебные записи справочника («Avocado, for use on
a sandwich»), блюда из недоступных продуктов и то, что у нас едят редко.

Итальянская, французская, грузинская, японская, среднеазиатская
и ближневосточная кухни остаются целиком. Ничего не удаляется физически:
непривычные блюда остаются в справочнике, и на вопрос о них агент ответит —
в автоматический подбор рациона они просто не идут.
